# UE04 – Forge ton code

## Présentation

Ce projet a été réalisé dans le cadre du rattrapage de l'UE04 **« Forge ton code »** à HETIC.

L'objectif était de reproduire le plus fidèlement possible la page **Histoire HETIC** en utilisant **HTML, CSS et JavaScript**.

J'ai essayé de respecter au maximum la structure de la page, les différentes sections, les contenus, les images, les boutons, les cartes, le footer ainsi que le responsive afin d'obtenir un rendu proche de la page de référence.

---

# Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

Pour m'aider pendant le développement, j'ai également utilisé plusieurs outils :

- ChatGPT et Gemini pour m'aider à comprendre certaines difficultés techniques.
- Meta AI pour recréer certaines images à partir de captures d'écran lorsque cela était nécessaire.
- Remove.bg pour supprimer l'arrière-plan de certains logos.
- Certaines images ont été téléchargées directement depuis le site HETIC afin de reproduire la page le plus fidèlement possible.

# Difficultés rencontrées

La principale difficulté rencontrée a été la réalisation du header.

J'ai eu des difficultés à gérer le changement de couleur du logo lorsque le header change d'apparence au survol et lors du défilement de la page. Pour résoudre ce problème, j'ai utilisé deux versions du logo, une blanche et une noire, afin de gérer correctement son affichage.

Le responsive a également été une partie importante du projet. Au départ, je ne savais pas comment adapter correctement toutes les sections pour les petits écrans. Je me suis donc inspirée du comportement responsive du site HETIC afin de créer une version adaptée avec mon propre code.

J'ai également rencontré quelques difficultés concernant certaines images. Pour reproduire la page le plus fidèlement possible, certaines images ont été téléchargées directement depuis le site HETIC tandis que d'autres ont été recréées avec Meta AI à partir de captures d'écran lorsque cela était nécessaire.
